# NINA

Presentadora virtual dominicana para vídeos, historias, novelas y frutinovelas.

## Estado actual

Primera base de la aplicación web independiente. Incluye:

- Interfaz adaptable a escritorio y móvil.
- Carga y reproducción local de vídeos en el navegador.
- Selector de los cuatro modos: Comentarista, Narradora, Protagonista y Automático.
- Controles iniciales de visibilidad y tamaño del avatar de referencia.
- Panel de voz dominicana y panel de exportación transparente preparados para las siguientes fases.

## Próximas fases

1. Integrar el personaje definitivo aprobado por el usuario.
2. Sistema de animación facial y corporal.
3. Voz femenina dominicana y sincronización labial.
4. Análisis del vídeo y generación de reacciones en los cuatro modos.
5. Superposición independiente con fondo transparente.
6. Exportación WebM con alfa y evaluación de MOV ProRes 4444.

> La voz, la comprensión automática de escenas, las reacciones inteligentes y la exportación transparente todavía no están implementadas en esta primera base.

## Requisitos

- Node.js 20 o superior.
- npm.
